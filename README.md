
# PRODIGY_GA_02

## Image Generation with Pre-trained Models

This project demonstrates image generation using a pre-trained Stable Diffusion model.

### Objective

Generate images from text prompts using a pre-trained generative AI model.

### Tools Used

* Python
* Google Colab
* Diffusers
* Stable Diffusion

### Example Prompt

"A futuristic city at night with flying cars"

### Output

The model successfully generated an image based on the given text prompt.
